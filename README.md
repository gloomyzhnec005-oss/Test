# ⚔️ Telegram Quest — мобильная MMORPG для Telegram

Многопользовательская 2D-RPG, которая запускается прямо в Telegram как **Mini App**.
Игрок выбирает одного из **трёх героев**, ходит по карте и убивает монстров вместе с другими игроками.

## Стек (готовая сборка)

| Часть | Технология |
|---|---|
| Клиент (игра) | [Phaser 3](https://phaser.io) — тайловая карта, спрайты, частицы, камера |
| Мультиплеер | Node.js + Express + [Socket.IO](https://socket.io) (авторитарный сервер, 10 тиков/с) |
| Бот | [Telegraf](https://telegraf.js.org) — кнопка «Играть» открывает Mini App |
| Авторизация | Проверка подписи `Telegram.WebApp.initData` (HMAC-SHA256) |
| Сохранения | JSON-файл `data/players.json` (уровень, опыт, золото, убийства — у каждого героя свои) |

Вся графика рисуется процедурно (pixel-art на Canvas) — внешних ассетов нет.

## Лобби (в стиле Lineage 2)

- В центре на магическом круге стоит выбранный герой, остальные позади. Нажатие на героя выводит его в центр.
- **Окно 1** — ник, уровень, класс, HP, мана (маг) или энергия (воин, лучник), опыт.
- **«Начать»** — вход в мир выбранным героем.
- **Меню**: «Персонаж» (один из трёх бесплатных, с характеристиками) и «Фон лобби».
- **Фоны**: «Тронный зал» и «Лесной алтарь» бесплатно; «Логово дракона» (50 ⭐) и «Ледяная цитадель» (75 ⭐) —
  платные, покупаются за Telegram Stars (счёт создаёт бот, покупка сохраняется на сервере). Цены — в `server/config.js`.
- Два места с замком — под будущих героев.

## Игровой процесс

- **3 героя:**
  - 🛡 **Воин** — 160 HP, ближний бой мечом
  - 🔮 **Маг** — огненные шары на дальнюю дистанцию, мало HP
  - 🏹 **Лучник** — быстрый, часто стреляет издалека
- **Монстры** (чем дальше от города — тем опаснее): Слизень → Волк → Скелет → Орк → **Дракончик** (босс)
- Опыт, уровни (рост HP и урона), золото, счётчик убийств
- Монстры замечают героя, преследуют и атакуют; после смерти возрождаются через 12 с
- Смерть героя → возрождение в городе через 4 с
- Регенерация HP вне боя, криты (x2), всплывающие цифры урона
- Другие игроки видны в реальном времени, общий чат, мини-карта
- Управление: **джойстик** слева, **кнопка атаки** справа (зажать — автоатака по ближайшей цели, герой сам подходит к ней), тап по монстру — выбрать цель. На ПК: WASD/стрелки + пробел
- Вибрация через Telegram HapticFeedback

## Быстрый старт (локально)

```bash
npm install
cp .env.example .env     # для локального теста бота можно не настраивать
npm start
```

Откройте http://localhost:3000 — без Telegram вход работает в гостевом режиме (`ALLOW_GUESTS=true`).

## Подключение к Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите `BOT_TOKEN`.
2. Разместите сервер на HTTPS-домене (Render, Railway, VPS + nginx/Caddy) или для теста используйте туннель:
   ```bash
   npx localtunnel --port 3000   # или: ngrok http 3000 / cloudflared tunnel --url http://localhost:3000
   ```
3. Заполните `.env`:
   ```
   BOT_TOKEN=...
   WEBAPP_URL=https://ваш-домен
   ```
4. `npm start` — сервер запустит и бота. Напишите боту `/start` и нажмите **⚔️ Играть**.
5. (Необязательно) В @BotFather: `/newapp` — чтобы игра открывалась по ссылке `t.me/<бот>/<app>`.

Чтобы пускать только игроков из Telegram, поставьте `ALLOW_GUESTS=false`.

### Docker

```bash
docker build -t tg-mmorpg .
docker run -p 3000:3000 --env-file .env -v $(pwd)/data:/app/data tg-mmorpg
```

## Структура

```
server/
  index.js    — HTTP + Socket.IO, игровой цикл, ИИ монстров, бой, опыт
  config.js   — классы героев и монстры (баланс правится здесь)
  world.js    — генерация карты (шум, озёра, леса, город, дороги)
  auth.js     — проверка initData от Telegram
bot/
  bot.js      — Telegram-бот (Telegraf)
public/
  index.html  — лобби + HUD
  css/style.css
  js/textures.js — процедурная pixel-art графика
  js/backgrounds.js — фоны лобби (тронный зал, лес, логово дракона, ледяная цитадель)
  js/lobby.js    — лобби: сцена с героями, панель героя, меню, покупка фонов
  js/game.js     — сцена Phaser (карта, сущности, эффекты, бой)
  js/main.js     — Telegram WebApp API, джойстик, чат, мини-карта
```

## Протокол Socket.IO

| Событие | Направление | Данные |
|---|---|---|
| `join` | клиент → сервер | `{ cls, initData, guestId, guestName }` |
| `welcome` | сервер → клиент | карта, классы, монстры, статы |
| `move` | клиент → сервер | `{ x, y, dir }` (сервер проверяет скорость и стены) |
| `attack` | клиент → сервер | `{ targetId }` (сервер проверяет дальность и перезарядку) |
| `state` | сервер → все | игроки, монстры, эффекты (10 раз/с) |
| `stats` | сервер → клиент | уровень, XP, HP, золото |
| `chat` | оба | сообщения |

HTTP: `GET /api/config`, `POST /api/profile` (уровни героев и купленные фоны), `POST /api/invoice` (счёт в Telegram Stars).
