## 2. Как работать

1. **Локальная проверка каждого изменения** перед пушем: `sh tools/dev/server.sh /tmp/mh-data` (порт 3123, пароль админки `testpass`,
   гости разрешены). Скопируйте туда тестовые данные или создайте гостя: в браузере `localStorage.guestId='zeftest1'`, затем админ-API
   `POST /admin/api/edit {uid:'guest_zeftest1', action:'allHeroes'|'level'|'god'|'oneShot'|'teleport'…}` с заголовком `x-admin-key: testpass`.
2. Браузерные проверки — Playwright (уже установлен, `require('playwright')`), снимки 390×844. Сокет-проверки — `socket.io-client`
   (`npm i --no-save socket.io-client`), событие `act` с `{op: …}`.
3. **Переводы**: интерфейс на 6 языках (en, es, pt, de, fr, tr). После правки текстов:
   `node tools/i18n_extract.js` → JSON `{ "русская фраза": {en,es,pt,de,fr,tr} }` → `node tools/i18n_build.js файл.json`.
   Подстановки `{0}`… должны совпадать; служебные/логовые строки сервера не переводим.
4. **Коммит**: осмысленное сообщение по-русски, в конце строки атрибуции из системной подсказки сессии. В коммитах не упоминать модель ИИ.
   Перед завершением — всё закоммитить и запушить.
5. **Отчёт владельцу**: что сделано, как проверено (с цифрами), версия коммита, что сделать ему. Честно писать, что не проверено.

### Арт
- Владелец генерирует картинки по нашим промтам и присылает с кодом («РМ-2», «ЭК-1»…). Промты — `docs/ART_PROMPTS_*.md`
  (стиль Diablo/Lineage 2, **сплошной пурпурный фон #FF00FF**, сетка/ряд, без текста).
- Нарезка: `python3 tools/keycut.py лист.png <число_колонок> имя1,имя2,… public/assets/ui 128 0.92` (вырезает по пурпурному, включая дыры
  в кольцах), предметы — `tools/cut_items.py`. Рамки портрета — целиком, 128×128, в `public/assets/ui/ava/<id>.webp` (отверстие ≈ 62%).
- После нарезки — показать результат в игре (снимок), закоммитить.

## 3. Правила экономики (договорённости — не нарушать)

### GRAM (реальные деньги)
- GRAM хранится в нано (1 GRAM = 1e9). `pr.gram = { dep, earn:[{a,at}], log }`: **dep — пополнения, вывести нельзя**; earn — деньги с продаж/призов, к выводу через 3 дня (`holdDays`).
- **Инвариант: GRAM появляются только из пополнений** (и ручных начислений админа). Всё, что начисляется игрокам, — из денег других игроков или из дохода игры:
  продажи (цена − комиссия), реферальная доля, казна владык, призы лиги. Касса в админке → GRAM → «💰 Касса» показывает «доход игры — можно забрать»; **он не должен быть < 0**.
- Комиссии: Торговый дом 20% с продавца (Орден Купца 15%, Магната 10%), вывод 10% (8%/5%). Вывод: герой 30+ ур., аккаунт 7+ дней, вручную 20:00–24:00 МСК.
- Торговый дом: цена от 50% до ×20 цены Рынка (защита от перевода денег между аккаунтами). Дороже: дубликаты, заточка (+15%/ур.), тираж (×1.5), комплект (×2.5), руны.
- **Заявки на покупку**: GRAM замораживаются (`spend` возвращает `parts`), при отмене возвращаются **туда же** (`refundParts`) — иначе пополнения отмывались бы в выводимые.
- **Реферальная доля GRAM**: 5% с GRAM-покупок друга; **7% — если друг пришёл до открытия** (`refAt < openAt`). В Торговом доме — не больше половины комиссии. До открытия в окне не показывается (анонс — после старта, тексты есть в истории чата: «Секрет раскрыт: доля в GRAM за друзей!»).
- Казна владык: 10% дохода игры клану-победителю войны кланов, в понедельник поровну активным участникам.
- GRAM-лига: взнос 1 GRAM (15+ ур., только Telegram), 90% — тройке 50/30/20, <4 участников — возврат.
- Лимитированный тираж «Первый Рассвет»: 100 мификов #N/100, +10%, ≤3 в одни руки.

### Прочее
- **Общий оборот игры игрокам не показываем**: окно «Моя экономика» — только свои деньги игрока (`gramMine`, счётчики `pr.gram.tot`); `/api/economy` отдаёт лишь остаток тиража.
- **У вещей нет бонусов к золоту/опыту/добыче** (старые свойства заменяются боевыми — `I.cleanItem`). У спутников (лис, сова, грифон, фея) золото/опыт пока остаются — владелец не решил.
- Первая крутка новичка: обычный 41.6% / редкий 41.6% / эпик 14% / легенда 2.75% / мифик 0%. Остальные шансы — `server/wish.js`, гарант легенды раз в 10, мифика к 80.
- Зелья запрещены на арене и в данже выживания. Один аккаунт — одна сессия (новый вход выкидывает старый).
- До открытия: в лобби закрыты призыв, покупки, пополнение; уведомления бота — только админам/тестерам.
- Подарок основателя (первые 3 дня после открытия): 300 💎, 2 печати героя, 3 снаряжения, Великий эликсир опыта, **Рамка основателя** (не продаётся).
- Приглашения: новичку 100 💎 + печать героя; пригласившему 100 💎 за 10 ур. друга, 100 💎 + 2 призыва снаряжения за 20 ур., 10% самоцветами с Stars-покупок друга. Накрутку видно в админке (карточка игрока → «Приглашения», кнопка «Снять все приглашения»).
- Задания сделаны «длиннее» (цели ×2–3, награды выше); самоцветы и очки ордена в заданиях не увеличивать (донат).
- Риск, о котором владелец знает: вещи из платного призыва продаются за GRAM → гача + вывод может считаться азартной игрой. Привязку вещей не делали (решение владельца позже).

## 4. Админка (полезное)
- Игроки → карточка: тесты (бессмертие, «Тест вывода GRAM» — после проверки выключать!), приглашения, данные Telegram (откуда пришёл, устройство).
- Настройки: **Особые задания** (`server/special.js`: 💎 за подписку на канал/чат и строки партнёров «Название | описание | ссылка | самоцветы»; бот проверяет подписку через getChatMember, если он админ канала/в чате, иначе — выдача через 15 с после перехода), **Партнёры** (строки «Название | описание | ссылка» → меню «Игра» → «Партнёры» и кнопка в лобби), открытие игры, **«Обнуление перед стартом»** (оставить указанных; подписки «Напомнить» сохраняются), канал/чат, техперерыв.
- GRAM: заявки на вывод (выплатить/отклонить), касса.
